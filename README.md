One image summing up Saturday 21 November 2026's world news, for make.fun's "Sum up 21 November's world news in one image" bounty. The poster names the day and shows six stories of that day across regions and fields — BepiColombo entering orbit at Mercury, an Israeli drone strike on a food truck in Gaza, a drone hitting a Russian cargo ship in the Gulf of Finland, Saudi Arabia intercepting three Houthi missiles at Riyadh, Bangladesh's garment-factory strike, and the Indonesia–EU trade agreements — with a ticker of three more. Events sourced from Wikipedia's Current events portal for 21 November 2026.

The image is drawn by `draw_entry.py` (Pillow, rendered at 2048×2048 and downscaled to 1024×1024); the committed `entry.png` is the entry.

## Run it

```sh
node --version   # not needed; the entry program is Python
python3 main.py  # writes /output/entry.png (set MAKEFUN_OUTPUT_DIR to choose another directory)
```

`main.py` copies the repository's `entry.png` to `/output/entry.png`: no network, and two runs write the same bytes.
